# Repository guidance

This repository is the public, English-language **Agent HQ Codex starter kit**. It contains a full implementation specification, a safe bootstrapper, and concept art. It does **not** ship a prebuilt Agent HQ dashboard.

If asked to build Agent HQ, first read `prompts/AGENT_HQ_MASTER_PROMPT.md` and `prompts/BRANDING_ADDENDUM.md` fully. Implement in the separate `workspace/` directory and follow local authorization boundaries. Never fabricate active agents, progress or tool connectivity. Do not introduce network exposure or paid services without approval.

If modifying this starter repository, preserve the master prompt and keep the README accurate about what is implemented vs proposed.
